# SL UI Library 1.1.0

234 interactive components across ten categories, with 236 standalone export variants. This release adds **124 components** to the initial 110-component public library. All public labels, usage notes and downloadable packages are English.

## New components

| Category | Added since the initial release | Total |
| --- | ---: | ---: |
| Buttons | 10 | 20 |
| Inputs | 10 | 20 |
| Toggles | 10 | 20 |
| Checkboxes | 10 | 35 |
| Sliders | 14 | 34 |
| Menus | 10 | 25 |
| Navigation | 10 | 20 |
| Overlays | 10 | 20 |
| Feedback | 20 | 20 |
| Data display | 20 | 20 |

- **Feedback** now includes alerts, progress and loading states, explicit form validation, empty-state recovery, draft status and other local feedback patterns.
- **Data display** now includes metrics, tables, charts, calendars, grouped rows, a selectable funnel, score matrix, treemap, cycle comparisons, heatmap and histogram.
- **Everyday sliders** cover cart quantity, reading spacing, content width, card spacing and thumbnail size. The rejected threshold-capacity draft is excluded.
- Other additions include duplicating an item, split actions, cancellable work, grouped checkbox rules, date ranges, duration and unit inputs, navigation destinations and locally scoped panels.

## Refinements

- Neutral charcoal and gray interface colors throughout the library. Meaningful chart, status and color-picker colors remain separate from the theme.
- Custom-styled date, time, unit and color pickers replace visible native pickers. The attachment preview uses sample files without opening the computer's file chooser.
- Clicking panel content or padding no longer dismisses menus and overlays. Explicit actions, Escape and outside clicks keep their intended behavior.
- Clearer navigation, reversible reading-queue actions, corrected priority ordering and improved table, notification and shortcut typography.
- Data display selection no longer adds redundant underlines. Funnel bars animate between percentage bases, comparison values no longer look like draggable handles, and histogram counts are centered above the columns.
- Form checks report visible field errors or a local confirmation. No backend submission is implied.

## Plugin and source

The Codex and Claude Code plugin manifests, offline catalog and source bundle are version 1.1.0. Components remain self-contained HTML, CSS and JavaScript with bundled fonts, project-owned SVGs, integration examples and semantic palette variables. The existing MIT and Instrument Sans OFL licenses are unchanged.

Install or update through your host's plugin manager and start a new task. Palette adaptation and integration require the agent to have access to the target project. Updating the plugin does not rewrite components already copied into an application. The opt-in catalog update channel remains unpublished and disabled by default; there is no telemetry or public ChatGPT plugin-directory listing.

## Verification and limits

Sources, generated previews, source views, standalone ZIPs and the offline plugin bundle are checked together. Browser review covers pointer and keyboard interaction, repeat activation, reset/cleanup, narrow layouts and reduced motion. Current browser evidence is Chromium on Windows; Firefox, Safari, physical touch devices and screen-reader speech are not exhaustively tested. Consumers must connect preview-only actions to real application operations and check contrast after changing the palette.
