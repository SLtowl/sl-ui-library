# SL UI Library 1.2.4

Website analytics now counts only daily visitor estimates, Home/Catalog pageviews and plugin ZIP download clicks. The consent popup and floating Privacy control are removed. The Download plugin ZIP button uses the existing relief CTA style, keyboard focus and reduced-motion behavior.

- Stateless cookieless measurement stores no browser/session identifiers or cookies. Previous explicit refusals and browser GPC/DNT remain respected. Legacy browser/session IDs are cleared.
- PostHog computes a daily host-scoped hash using the request IP and user agent, then removes both from stored events. IP storage and GeoIP enrichment stay disabled. Counts are estimates; daily hashes cannot deduplicate returning visitors across days.
- Component open/copy/download instrumentation is removed. No SDK, replay, autocapture, form values, searches or code are collected.
- Plugin activation remains offline by default and requires separate explicit consent. Download clicks and opt-in activations do not prove completed installations. The owner dashboard stays private.
- All 388 components and 390 export variants are unchanged. Source bundle SHA-256 remains 75c6aa8ef9a197c96118f083263f4c4ea299f6e77f68094dde9ae747d6246ea4.
