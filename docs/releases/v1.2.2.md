# SL UI Library 1.2.2

This patch publishes the owner-approved catalogue redesign and interaction fixes. The catalogue remains 388 components / 390 export variants across ten categories; no unreviewed components are added.

## Website

- New light home page, reversible entrance to the catalogue and return from the library title.
- Category navigation, component search, All / SL Original collection filters and incremental loading.
- White, charcoal and slate-blue preview palettes, including palette-aware source tabs and complete ZIP exports.
- Compact component workspace with interactive preview, reset, HTML/CSS/JavaScript/React/Next.js tabs, copy and ZIP download.
- Vertical How to use guide with small project-owned SVG diagrams.
- Browser-painted cursors, restrained text-selection styling and subtle 160ms coarse-wheel smoothing. Fine pixel scrolling and native component scrollers retain browser handling; reduced-motion preferences are respected.

## Component fixes

The owner-reviewed fixes cover Buttons, Inputs, Menus, Checkboxes, Toggles, Data display, Navigation, Overlays and Feedback. They address icon geometry, white-palette legibility and hover/selected states, clipped content and overlay backdrops, form interactions, numerical bounds, repeat activation, reversible animation and controller cleanup. Existing standalone sources and source-preserving React / Next.js adapters are retained together.

## Agent setup and documentation

- Matching English and Russian README files.
- Hermes Agent instructions using its supported external skill directories and the complete existing repository package. No third-party fork or Hermes-native plugin-catalog listing is required.
- Existing Claude Code and Codex installation/update commands remain available.
- Package, host manifests and bundled catalogue metadata advance together to 1.2.2 for version-aware updates.

## Verification and limits

The completed local audit records 390 controller-generation matches and 5,900 ZIP member comparisons, targeted palette exports, actual source-copy checks and nested React / Next.js menu checks. Subsequent shell changes have focused browser coverage for the guide, selection, scrolling and root/subpath publication. The final build/check run is recorded separately; optional browser suites are not all enabled by the default check.

The wider 555-clone colour rerun was deferred by the owner. No fresh full-library browser pass, physical-device certification, Firefox/Safari coverage or end-to-end Hermes conversation is claimed. Preview confirmations remain local demonstrations; production actions need real application callbacks.
