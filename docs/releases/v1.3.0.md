# SL UI Library 1.3.0

[Website](https://sltowl.com/) · [Catalog](https://sltowl.com/catalog.html) · [Documentation](https://sltowl.com/docs.html)

The redesigned home page leads to a catalog with collection covers, live previews, search and palette-aware source and ZIP exports. The website adapts its navigation and previews to narrower screens.

Product adds 51 components across Buttons, Inputs, Toggles, Checkboxes and Sliders. The catalog and offline agent bundle now include 439 components with 441 export variants. Each Product package includes vanilla source files and entry points for React and Next.js.

The website's primary address is now `sltowl.com`.
