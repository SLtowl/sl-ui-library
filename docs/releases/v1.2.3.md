# SL UI Library 1.2.3

This patch adds optional website analytics and separately consented plugin activation reporting. It keeps all 388 reviewed components and 390 export variants unchanged.

- Website analytics starts only after Allow analytics. Privacy reopens the choice; Decline stops capture and removes local analytics identifiers. Global Privacy Control and Do Not Track are respected.
- The site counts fixed Home/Catalog views, component source openings, successful source-copy actions and ZIP download clicks. Code, search text, input values and full URL queries/fragments are excluded. No session recorder, autocapture or error reporter is loaded.
- The plugin remains offline by default. Its explicit analytics preference command can report one activation after consent, retry the same event after an offline failure, inspect local status or disable reporting. Repository-based installs resolve the public configuration from the library website only after consent.
- Reports distinguish consenting visitors, download clicks and opt-in activations. These are not verified installation counts and do not reconstruct past activity.
- Component ZIPs contain no tracking. The component source bundle SHA-256 remains `75c6aa8ef9a197c96118f083263f4c4ea299f6e77f68094dde9ae747d6246ea4`.

The owner dashboard stays private; no public sharing, invitations, scheduled messages or paid upgrade are part of this change. Build-time ingestion configuration uses public project settings, never personal API keys.

See [privacy and command details](../agents.md#download-reporting-and-privacy).
