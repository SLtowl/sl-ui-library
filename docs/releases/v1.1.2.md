# SL UI Library 1.1.2

Patch release strengthening source-faithful agent integrations. The existing
297-component catalog (299 export variants) is unchanged.

## Changes

- Require agents to select a CLI-returned component ID, read the actual package
  files and retain their SHA-256 values as a source receipt before editing an app.
- Explicitly forbid presenting shadcn, Radix, framework controls, Unicode glyphs
  or screenshot-based reconstructions as SL UI source unless the owner requested
  that replacement.
- Make `audit <variant> <rendered-html-file>` exit nonzero when it reports
  `needs-review`, so automated workflows cannot silently accept a mismatch.
- Add a regression fixture for a shadcn-style reconstruction of the library's
  exclusive-none checkbox interaction.

## Scope and limits

The plugin can make the required workflow explicit and make audit failures
machine-visible. It cannot force an agent that was never activated, cannot inspect
a private host project without access, and does not rewrite components already
copied into a website. A passing source audit still requires visual, responsive,
keyboard, motion and behavior verification in the host application.
