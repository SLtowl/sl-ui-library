# SL UI Library 1.1.1

Patch release for integration diagnostics and reliable plugin update detection.
The existing 297-component catalog (299 export variants) is unchanged by this patch.

## Changes

- Add `audit <variant> <rendered-html-file>` to compare source class names and
  inline SVG geometry with a serialized component subtree after integration.
- Return integration guidance from `inspect` and `install`, including preservation
  of SVG icons, scoped styles, keyboard focus and host-app verification.
- Document update commands for Codex and Claude Code in the README.
- Align package, plugin manifests and generated catalog on version 1.1.1. The audit
  previously reached GitHub under 1.1.0; the version bump lets version-aware plugin
  managers recognize that update.
- Add regression coverage for missing markers, icon substitution, geometry changes
  and the audit tool's inclusion in the portable plugin archive.

## Scope and limits

The audit is a local, read-only heuristic. It does not contact or modify a website,
execute its scripts, or validate CSS, animation, accessibility or pixel fidelity.
Intentional class renames and equivalent SVG path syntax require manual review.
`source-markers-present` is not a visual pass; `needs-review` identifies differences
to investigate. Existing integrations are never automatically rewritten.

No new components, runtime dependencies, permissions or telemetry are introduced.
