Basic audience measurement

The website counts Home/Catalog views and plugin ZIP download clicks through PostHog EU. It stores no analytics cookies or browser/session identifiers. Global Privacy Control, Do Not Track and previous explicit refusals are respected. There is no analytics popup.

Daily visitor estimates

PostHog temporarily processes the request IP address and browser user agent to compute a daily hash scoped to this website. Stateless cookieless ingestion removes the IP address and user agent from the stored event. IP storage and GeoIP enrichment are disabled. The daily identifier changes each day; it is not a persistent visitor profile.

What is sent

Fixed Home/Catalog page names, a broad referral category, library version and plugin ZIP click events. No component interaction tracking, recordings, automatic DOM capture, conversations, code, form values, searches, full referral links or URL query strings. Exported components contain no analytics.

Plugin activation

The plugin is offline by default. Separately agreeing to activation reporting sends one random installation ID, event ID, plugin version and host category. It does not track ongoing use. Ask your agent to disable analytics, or run the bundled CLI with analytics disable, to clear that preference's identifiers.

Understanding the numbers

Daily visitors are estimates, not verified people. The same visitor on different days has different identifiers, so a period total cannot deduplicate returning people across days. Changed networks, shared connections and multiple browsers can affect counts. ZIP clicks do not prove completed downloads. Consented activations do not represent all installations. Privacy signals, blocked requests and direct GitHub downloads are not included.
