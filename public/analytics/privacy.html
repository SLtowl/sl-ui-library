Optional analytics

SL UI Library uses PostHog EU to understand visits, component interest and download clicks. Collection starts only after you choose Allow analytics. Choose Privacy, then Decline to stop future collection and clear the local analytics identifiers. Global Privacy Control and Do Not Track are respected.

What is sent

A random browser and session ID, fixed Home/Catalog page names, a broad referral category, library version, and IDs, palettes and source formats of components you inspect, copy or download. These IDs are not connected to an account. The service processes network requests; IP storage is disabled and events request no GeoIP enrichment.

What stays private

No recordings, automatic DOM capture, conversation content, copied source code, form input, search text, full referral links or URL query strings. Component ZIPs contain no analytics. You can use the full library after declining.

Plugin activation

The plugin is offline by default. Separately agreeing to activation reporting sends one random installation ID, event ID, plugin version and host category. It does not track ongoing use. Ask your agent to disable analytics, or run the bundled CLI with analytics disable, to clear that preference's identifiers.

Understanding the numbers

Visits count consenting browsers. ZIP clicks do not prove a completed download. Consented activations do not represent all installations. Declined analytics, blocked requests, older plugin versions and direct GitHub downloads are not included in those counts.
