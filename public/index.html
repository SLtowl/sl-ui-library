Using the library

Start with a type

Choose an icon tile on the home page to open a component category. Inside that category, search by name, action or motion.

Try it before you take it

Use a component’s live preview, then open it to see its HTML, CSS and JavaScript. Select the part you need and copy a file or download the complete zip.

Keep structure and motion separate

A component belongs to one type. Different motion treatments stay inside that type. Pair, Save and Cancel are export options for one component, not three separate components.

Bring it into your project

The current component uses plain HTML, CSS and JavaScript with a bundled font. Its download works offline. Edit the CSS variables and connect the actions to your own logic.
